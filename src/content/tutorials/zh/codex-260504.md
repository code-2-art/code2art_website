codex 里面开启了我的小宠物

方法特别简单

1 、让 codex 给你安装 hatch-pet 这个 skill

https://github.com/openai/skills/tree/main/skills/.curated/hatch-pet

2 、安装好后可以发送两类指令

```
$hatch-pet 帮我做一只像素风的小猫 Codex pet
```

这个是让他帮你画一个什么内容,你可以写像素风的海豹,冰淇淋等等

```
$hatch-pet 把这张狗狗照片做成 Codex pet
```

这个是你得放一张图给他

我就放了我自己的气球姑娘

<img src="/uploads/codex-260504/img_001.webp" alt="" loading="lazy" />

<img src="/uploads/codex-260504/img_002.webp" alt="" loading="lazy" />

3 、你允许他开 subagent 来干这后面一大堆的事情

就能看到他开始辛苦的绘画了(中间画错了一个部分,纠正了)

<img src="/uploads/codex-260504/img_003.webp" alt="" loading="lazy" />

4 、给我画了一大堆很可爱的娃娃跑步啊,招手啊,蹲下啊,辛苦啊,眨眼啊~

<img src="/uploads/codex-260504/img_004.webp" alt="" loading="lazy" />

最后就生成了一个跟着我 codex 工作情况关联的娃娃

5 、要在 设置——外观——宠物 里面选择我要的娃娃

重启+ 设置——外观——宠物里面点“唤醒宠物”

就 ok 了,会一直陪着你

<img src="/uploads/codex-260504/img_005.webp" alt="" loading="lazy" />

<img src="/uploads/codex-260504/img_006.webp" alt="" loading="lazy" />

6 、最后给大家介绍这个网站

https://hatch-pet.com/zh#enable-pet
