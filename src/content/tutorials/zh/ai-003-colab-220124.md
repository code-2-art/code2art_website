第一节课件已完成，是Google Colab的基本介绍，摘录部分重点在这里：

从界面上看，Colab就是一个**支持图文、代码混合排版，同时代码还能直接运行的超级在线文档**。

## **Runway、Colab、本机电脑三种运行环境对比**

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Runway** | **Colab** | **本机电脑** |
| 本地电脑配置 | **✔️**云服务无要求 | **✔️**云服务无要求 | 很高的配置 |
| 需要科学上网 | 不确定 | **需要** | 安装资源时可能需要 |
| 界面对艺术家设计师亲和 | **✔️** | 一般 | 残暴 |
| 开箱即用 | **✔️** | **✔️** | 开箱啥都没有 |
| 零代码要求 | **✔️** | 需要一点Python | 需要工程和运维能力 |
| 基础的训练和生成 | **✔️** | **✔️** | **✔️** |
| 支持的AI模型种类 | 有限制 | **✔️** 基本无限制 | **✔️** 会受电脑配置限制 |
| 功能扩展性 | 低 | **✔️**高 | **✔️**高 |
| 价格 | 高 | **✔️** 免费或低 | 显卡价格高 |
| **一句话总结** | 适合初学上手，  可用来快速生成插值动画。 | 基本可以用来作品生产，只受限于网络状况，  建议买Pro版，以及配合大容量Google Drive。 | 显卡贵，  大批新手倒在AI运行环境的安装和配置上，  跨过这一步海阔天空。 |
