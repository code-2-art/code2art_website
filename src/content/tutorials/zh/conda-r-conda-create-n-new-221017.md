从已有conda环境复制/克隆一个新环境：
conda create -n NEW --clone OLD
这个用法很适合已经有了一个搭建好的conda环境，之后在做新工程、体验新AI模型时，快速复制一个新环境出来，既免去了新建环境时种种安装步骤，也保证玩坏后标准环境还在。
