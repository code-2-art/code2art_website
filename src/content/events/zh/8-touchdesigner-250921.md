实验编程训练营第8期，AI、Proccessing、TouchDesigner、Unity 将不再是孤立的技能，而会构成一个互为支撑的体系，跨越人工智能 **× 算法 × 交互 × 虚拟空间**。

TouchDesigner单元今晚开启，由 3EYESNUTS 来讲这款新媒体展览和舞台艺术的重要工具，它强调数据与视觉的实时映射，使作品具备 “回应” 观众与环境的能力。

主讲：3EYESNUTS

数字/机械交互装置/生成影像的创作者。具有极其丰富的舞台演出与互动展项经验。

通过本单元学习，你将继AI、算法逻辑学习之后，开启新的节点式编程创作维度。

TD课程大纲

第一节：认识 TouchDesigner 与影像的构建

目标：零基础入门，理解TD的工作方式，能做出第一个动态图形。

* 课程导入

+ 交互艺术案例赏析（含传感器+TD的案例）

+ TouchDesigner 的定位与优势

* 软件基础

+ 界面结构、常用快捷键

+ OP 类型（COMP/TOP/CHOP/SOP/DAT/POP）

+ 节点连接与数据流思维

* 实操

+ 制作第一个动态影像：Noise + Transform

+ 改变参数，感受实时性

* 小结与作业

+ 使用不同的TOP组合做一个2D动态背景

<img src="/uploads/8-touchdesigner-250921/img_007.webp" alt="图片" loading="lazy" />

第二节：数据驱动影像

目标：学会用数值控制视觉变化。

* 回顾作业并答疑
* CHOP的核心作用与数据流

+ Constant/LFO/Math/Shuffle

* 参数绑定与表达式（export&reference）
* 图像/模型等数字资产的导入简介
* 实操

+ 用LFO控制图像或模型的旋转/缩放/颜色

+ 用Audio CHOP分析音乐并驱动图像变化

* 小结与作业

+ 让音乐、滑块等不同来源的数值控制视觉

<img src="/uploads/8-touchdesigner-250921/img_008.webp" alt="图片" loading="lazy" />

第三节：Arduino IDE的使用

目标：利用自带案例或AI工具编写第一段硬件程序，用串口输出硬件数据。

* 常见传感器简介

+ 距离（ToF、超声波）、加速度（MPU6050）、旋钮/推子、摄像头追踪等

* 硬件数据接口协议简介（ttl/i2c/spi等）
* Arduino IDE基础使用方法
* 实操示例

+ 使用串口传输电位器数据

+ 使用TD读取开发板发出的串口数据

<img src="/uploads/8-touchdesigner-250921/img_009.webp" alt="图片" loading="lazy" />

第四节：TouchDesigner 与传感器对接

目标：认识常用传感器和输入方式，并在TD中读取数据。

* 常见传感器简介

+ 距离（ToF、超声波）、加速度（MPU6050）、旋钮/推子、摄像头追踪等

* 数据输入方式

+ 数据接口协议简介（硬件：串口ttl/rs232/485等，网络：socket/udp/tcp/osc）

* 实操示例

+ 电位器 → Arduino兼容开发板 → TD控制图像大小

* 小结与作业

+ 使用物理旋钮数据代替第二节驱动影像的LFO数据，制作第一个由物理世界驱动的影像作品

<img src="/uploads/8-touchdesigner-250921/img_010.webp" alt="图片" loading="lazy" />

第五节：综合创作与展示

目标：经验/答疑及扩展

* 项目结构整理

+ 如何规划节点与数据流

+ 性能优化基础（分辨率、cook开关、GPU负载）

* 作品分享与讨论

+ 延伸学习方向（Python脚本、GLSL、灯光控制、声音控制）

🚀课程形式

* 周期：8月-10月，持续约2个月，前半程AI为主，后续AI和交互穿插。

* 方式：线上直播+录播+小班群答疑。
* 总课时：100小时以上，相当于报AI送交互，或报交互送AI。
* 持续报名：随到随学，所有课程均有回看，讲师团在小班群内随时交流答疑。

* 加入顶级校友会和社群资源。

❓常见问题

* AI与交互课能分开报吗？

  不拆分，总课时丰富，可以理解为50%是赠送。
* 没有编程基础，能学会吗？

  零基础友好，但需要投入时间和精力。
* 电脑要求？

  商业工具绝大部分是在线工具，上网本/苹果电脑均可。

  SD ComfyUI也有在线工具，学习够用，作为日常生产力建议配置高配Windows英伟达显卡。
* 工作学习忙，没跟上课程怎么办？

  支持永久回看，社群内随时可交流答疑。
