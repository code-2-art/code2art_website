1. ## **视频运动模块 AnimateDiff**

AnimateDiff，从真实世界视频中学习的可迁移的运动模块，结合Text to Image模型生成个性化的、时间上流畅的动画视频，同时保持视觉质量和运动多样性。

AnimateDiff MotionLoRA，是AnimateDiff的轻量级微调技术，它使预训练的运动模块能够以较低的训练和数据收集成本适应新的运动模式，例如不同的镜头类型。

* 论文：https://arxiv.org/abs/2307.04725
* AnimateDiff官方项目：

+ SD1.5版：https://github.com/guoyww/AnimateDiff
+ SDXL版：https://github.com/guoyww/AnimateDiff/tree/sdxl

* AnimateDiff（主）运动模块：

+ Hotshot-XL官方项目：https://github.com/hotshotco/Hotshot-XL
+ Hotshot-XL模型下载：https://huggingface.co/hotshotco/Hotshot-XL/tree/main
+ hsxl\_temporal\_layers.f16.safetensors 或 hsxl\_temporal\_layers.safetensors 均可。
+ 下载：https://huggingface.co/guoyww/animatediff/tree/main
+ SD1.5：v3\_sd15\_mm.ckpt
+ SDXL：mm\_sdxl\_v10\_beta.ckpt
+ \*SDXL版AnimateDiff替代品：Hotshot-XL

* AnimateDiff MotionLoRA：

+ 适用于特定运动模式，如相机缩放、滚动等。
+ 如v2\_lora\_ZoomIn.ckpt、v2\_lora\_RollingClockwise.ckpt等。
+ 模型下载：https://huggingface.co/guoyww/animatediff/tree/main
+ 文档：https://github.com/guoyww/AnimateDiff?tab=readme-ov-file#demos-motionlora

<img src="/uploads/comfyui-ai-4-14-241017/img_002.webp" alt="" loading="lazy" />

* AnimateDiff Domain Adapter LoRA ：

+ 对图像模型微调，可提供更大的推理灵活性。
+ v3\_sd15\_adapter.ckpt
+ 模型下载：https://huggingface.co/guoyww/animatediff/tree/main
+ 文档：https://github.com/guoyww/AnimateDiff?tab=readme-ov-file#animatediff-1

## **安装步骤**

1. 加载workflow
2. 安装缺失的插件
3. 管理器中“更新全部”，更新ComfyUI主体和插件版本
4. 按照workflow里的提示，下载安装所有的模型

1. SD大模型
2. LoRA模型
3. Animatediff模型、Animatediff LoRA模型
4. IPAdapter运行所需的clip vision模型
5. IPAdapter本体模型
6. ControlNet模型
7. 放大器（upscale）对应的模型
8. 插帧对应的模型

5. ControlNet的遮罩视频，换成本地的mp4文件
