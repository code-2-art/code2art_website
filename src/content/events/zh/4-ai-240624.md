暑期将至，实验编程线上训练营4期《生成式AI从原理到应用》报名开启🚀

**训练营4期****内容简介**

* AI与机器学习基础
* 生成式AI原理

+ 图像生成模型 Diffusion/GAN/VAE
+ 大语言模型 ChatGPT

* 三大AI绘画模型核心区别与选型

+ Midjourney
+ DALL·E / ChatGPT
+ Stable Diffusion

* Stable Diffusion核心基础

+ 安装
+ 模型基础（大模型、LoRA、Textural Inversion）
+ 提示词
+ 扩展插件
+ ControlNet
+ 模型训练

* ComfyUI

+ 工作流原理
+ LoRA、ControlNet
+ IPAdapter、InstantID应用
+ Animatediff 动态影像
+ 综合应用实例解析系列

* 高阶应用

+ 创意编程基础与API
+ ChatGPT API调用
+ SD WebUI与ComfyUI服务搭建

* 配套课程选修

+ Google Colab
+ StyleGAN
+ 破除代码恐惧：环境搭建、命令行操作、爬虫脚本
+ AI与交互装置
+ AI 3D生成

以上是大框架，具体课表会更详细。
