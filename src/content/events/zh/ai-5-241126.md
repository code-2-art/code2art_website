**🚀训练营5期详细介绍**

|  |  |
| --- | --- |
| **实验编程AI艺术训练营第5期** | |
| **上课方式** | 线上直播 + 录播 + 图文资料 + 专家答疑 |
| **开营时间** | 11.25 |
| **适合人群** | 零基础到进阶，从入门到放肆 |
| **课程体系** | 基础课 + 专题课 + 大帅课 |

本期训练营覆盖图像模型与大语言模型，包括AI视觉艺术与影像短片创作、写作、音乐、多种产业落地案例分析、实时AI交互、点云与三维扫描，还有模型训练和AI编程基础。

更是在AI原理与实践并重的基础上，加强了创作方法论与AIGC美学。
