TD课程大纲：

第一节：认识 TouchDesigner 与影像的构建

目标：零基础入门，理解TD的工作方式，能做出第一个动态图形。

* 课程导入

+ 交互艺术案例赏析（含传感器+TD的案例）

+ TouchDesigner 的定位与优势

* 软件基础

+ 界面结构、常用快捷键

+ OP 类型（COMP/TOP/CHOP/SOP/DAT/POP）

+ 节点连接与数据流思维

* 实操

+ 制作第一个动态影像：Noise + Transform

+ 改变参数，感受实时性

* 小结与作业

+ 使用不同的TOP组合做一个2D动态背景

<img src="/uploads/touchdesigner-8-ai-250813/img_008.webp" alt="" loading="lazy" />

第二节：数据驱动影像

目标：学会用数值控制视觉变化。

* 回顾作业并答疑
* CHOP的核心作用与数据流

+ Constant/LFO/Math/Shuffle

* 参数绑定与表达式（export&reference）
* 图像/模型等数字资产的导入简介
* 实操

+ 用LFO控制图像或模型的旋转/缩放/颜色

+ 用Audio CHOP分析音乐并驱动图像变化

* 小结与作业

+ 让音乐、滑块等不同来源的数值控制视觉

<img src="/uploads/touchdesigner-8-ai-250813/img_009.webp" alt="" loading="lazy" />

第三节：Arduino IDE的使用

目标：利用自带案例或AI工具编写第一段硬件程序，用串口输出硬件数据。

* 常见传感器简介

+ 距离（ToF、超声波）、加速度（MPU6050）、旋钮/推子、摄像头追踪等

* 硬件数据接口协议简介（ttl/i2c/spi等）
* Arduino IDE基础使用方法
* 实操示例

+ 使用串口传输电位器数据

+ 使用TD读取开发板发出的串口数据

<img src="/uploads/touchdesigner-8-ai-250813/img_010.webp" alt="" loading="lazy" />

第四节：TouchDesigner 与传感器对接

目标：认识常用传感器和输入方式，并在TD中读取数据。

* 常见传感器简介

+ 距离（ToF、超声波）、加速度（MPU6050）、旋钮/推子、摄像头追踪等

* 数据输入方式

+ 数据接口协议简介（硬件：串口ttl/rs232/485等，网络：socket/udp/tcp/osc）

* 实操示例

+ 电位器 → Arduino兼容开发板 → TD控制图像大小

* 小结与作业

+ 使用物理旋钮数据代替第二节驱动影像的LFO数据，制作第一个由物理世界驱动的影像作品

<img src="/uploads/touchdesigner-8-ai-250813/img_011.webp" alt="" loading="lazy" />

第五节：综合创作与展示

目标：经验/答疑及扩展

* 项目结构整理

+ 如何规划节点与数据流

+ 性能优化基础（分辨率、cook开关、GPU负载）

* 作品分享与讨论

+ 延伸学习方向（Python脚本、GLSL、灯光控制、声音控制）

❓常见问题

* AI与交互课能分开报吗？

+ 不拆分，总课时丰富，可以理解为50%是赠送。

* 我是小白/我没有编程基础，能学会吗？

+ 零基础学习没有任何问题，但需要投入时间和精力。

* 电脑要求？

+ 商业工具绝大部分是在线工具，上网本/苹果电脑均可。
+ SD ComfyUI也有在线工具，学习够用，作为日常生产力建议配置高配电脑。
+ 模型训练也有在线工具，长期训练建议配置高配电脑。

* 工作学习忙，没跟上课程怎么办？

+ 支持长期回看，社群内随时可交流答疑。
