第 8 期训练营的**第2次直播课程**，围绕“大语言模型（LLM）与多模态”的实操能力展开，覆盖 Kimi/ChatGPT/DeepSeek/豆包等中文生态，以及 Google Gemini与 NotebookLM 的前沿用法。重点不止于“知道”，更在于**会用、用好、用出结果，学习**如何用当下最强的通用模型，将**创意—结构化—落地产出**串成闭环。

**本节直播回顾**

 1. 本节产出（学完能做什么）

* 用 LLM 快速产出**人物/场景卡**与**分镜表**（含镜号、时码、机位、景别、音效等）。
* 将分镜表直接转为**图像提示词**，在即梦/Midjourney 生成**分镜参考图**。
* **在 ChatGPT/Gemini 内完成**图像局部修正**（如字形纠错），减少反复导出导入。**
* **通过 Google Gemini（AI Studio）**自动生成可用网页工具**（提示词生成器 + 模型 API 直连）。**
* **用 NotebookLM 建立**资料库→要点摘要→脑图→音/视频讲解**的知识工程。**

 2. 本课核心方法 

* **三步法：**①设定专业角色（导演/编剧/工程师）；②对齐行业范式（如《Save the Cat!》节拍）；③注入自有语料（剧本/资料）提升风格一致性与可控度。****
* ****四条生产线：******A. 剧情：一句话梗概 → 人物表（服化道/色调）→ 场景表 → 分镜脚本  
  B. 影像：分镜表直转**图像提示词** → 即梦/MJ 生成分镜图  
  C. 精修：在 ChatGPT/Gemini 内完成**局部修复**（如图中文字纠错）  
  D. 自动化：用 Gemini 直接**生成可用 Web 工具**（提示词生成器 + 模型API预览）**

## 

 3. 关键工具与最佳实践

* ********Kimi / ChatGPT / DeepSeek / 豆包**：中文场景下稳定输出**结构化内容**（表格、卡片、分镜）。******
* **Google Gemini（AI Studio）：多模态 + 代码生成 + 在线预览，实现“需求→代码→成品”一体化。**
* ****NotebookLM**：把分散资料变成**可检索的知识本**，支持脑图与音/视频讲解，显著缩短消化时间。**

* ****图像局部修正**：给出**明确的局部约束**与“保持其余元素不变”的指令，多次抽样获得稳定结果。**

 4. 标准工作流

①设定角色+范式对齐+注入语料

②生成人物/场景卡（含可直接用于绘制的视觉要素）

③输出分镜工程（**镜号/时码/机位/景别/运动/画面/光效/音效**的表格化分镜）

④即梦/MJ 出分镜图；在模型内做**局部校正**，减少往返

⑤用Gemini 生成**提示词生成器**等小工具，沉淀为团队资产。

⑥用Gemini **生成小工具**（如提示词生成器），沉淀为团队资产

⑦用NotebookLM **沉淀资料→摘要→脑图/讲解**
