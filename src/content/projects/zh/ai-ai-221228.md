分享一名用户的使用案例，TA 输入**食材：章鱼、全鸡、猪眼球** 及 **食用场合：克苏鲁聚餐**，获得的 AI 黑暗料理菜谱为：**章鱼全鸡**。

**章鱼全鸡制作指南**

1. 章鱼洗净，去除内脏，切成大块；全鸡洗净，去除内脏，切成大块；猪眼球洗净，切成块；洋葱去皮，切成小块；胡萝卜去皮，切成小块；番茄去皮，切成小块；蒜头去皮，切成末；姜切片。

2. 将章鱼、全鸡、猪眼球、洋葱、胡萝卜、番茄放入锅中，加入充分的清水，大火煮滚。

3. 将火调小，转为中火，加入料酒、盐、黑胡椒粉、花椒粉、香菜叶、蒜末、姜片、胡椒粉，继续煮15分钟。

4. 加入西兰花，煮5分钟，汤汁收干即可。

**AI 黑暗料理生成器的制作指南**

12月9日，Twitter 小圈子内出了一条爆炸新闻，API 整合工具 Zapier 宣布上线了 OpenAI 的模型，用户可以调用 OpenAI 的 Dall-E2 绘画模型，以及 GPT-3 模型，开发自己的自动化工作流或者应用程序。

<img src="/uploads/ai-ai-221228/img_003.webp" alt="" loading="lazy" />

什么是自动化工作流？这里做一个简单的背景知识补充 [1]

自动化工作流是指解决人类在日常工作中遇到的重复性任务的工具。随着信息时代的到来，许多人需要在不同的系统或软件之间倒来倒去，甚至手动输入，而自动化工作流的出现就是为了提高效率。

**每个应用内部的自动化程度往往容易优化，但应用和应用之间的壁垒却难以消除。**这是目前普通用户想构建自动化工作流的最大阻碍。

目前解决这一个问题有两个主要的思路，第一条就是使用类似飞书这样的超级 APP, 这样相当于把不同应用之间的壁垒转化为了单一应用间的自动化问题；而第二条就是利用 API 的整合去实现应用间的信息互通。

API (Application Programming Interface) 是应用之间相互通信和交互的接口，你可以**把 API 简单理解为是开发者把某些功能打包封装以后开放给别的开发者使用。**

<img src="/uploads/ai-ai-221228/img_004.webp" alt="" loading="lazy" />

这样的 API 集成平台其实蛮多的，国外比较有名的就是 IFTTT 和 Zapier, 国内则是集简云。这次选择 Zapier 也只是恰好因为其上架了 OpenAI 的模型，这给应用程序/自动化工作流带来了不小的想象力。

比如有人通过 Zapier 来串联 GPT-3 和 Gmail，**让 AI 自动完成回复邮件的草稿**；有人通过 Zapier 串联 Dall-E2 和 Discord, **在自己的 Discord 频道里建立 Dall-E2 的画画机器人**。

而我的 AI 黑暗料理生成器就是通过 Zapier，串联网络表单（Google Form 或 Webform）、OpenAI 的 GPT-3 和 Dall-E2、以及 Gmail 来实现。

<img src="/uploads/ai-ai-221228/img_005.webp" alt="" loading="lazy" />

首先通过 Zapier 登录相关应用账号，整个自动化工作流 Breakdown 为以下 5 个步骤：

1. 当 Webflow 里收集到新填写的表单信息后，自动触发整个流程。

2. 将 Webflow 里收集到的结果，作为 Prompt 的一部分发送给 OpenAI 的 text-davinci-003 模型。红框里的部分就是我发送给 text-davinci-003 的 prompt, 可以将表单结果中的不同问题的答案，自动作为 prompt 的内容。

<img src="/uploads/ai-ai-221228/img_006.webp" alt="" loading="lazy" />

3. 将 Webflow 里收集到的结果，翻译成英文。做这个操作的原因是我计划用 Dall-E2 来生成菜谱样图，但 Dall-E2 只允许通过英文来生成图像。

<img src="/uploads/ai-ai-221228/img_007.webp" alt="" loading="lazy" />

4. 将翻译成英文的内容，发送给 OpenAI 的 Dall-E2 让其生成图像。

<img src="/uploads/ai-ai-221228/img_008.webp" alt="" loading="lazy" />

5. 将第 2 步生成的菜谱，和第 4 步生成的图像，发送给 Webflow 里收集到的对应表单的邮箱中。

<img src="/uploads/ai-ai-221228/img_009.webp" alt="" loading="lazy" />

整个流程就设置好了，设置好以后点选 **Publish** 就可以上线这个项目。整个过程中没有任何使用到代码的地方。

这件事对于我的刺激还挺大的，这代表着我可以以非常低的成本**将最新的 AI 模型整合到自己的工作流中**，**还能快速地来实验和迭代一些新想法**。这个事情本身就非常酷。之后有时间我还会实验 IFTTT 和集简云。

想到 OpenAI 很快就要出 3D Dall-E 和 GPT-4 （据传 10 倍胜过 GPT-3.5）了，2023 年也将会是备受期待、充满可能性的新一年。
